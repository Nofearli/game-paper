## 2. Research Background

Target-defense problems — protecting a target set from an adversarial intruder — are a canonical application class of differential games since Isaacs' 1965 monograph [1], which posed a pursuer-vs-evader target-defense game and decomposed it into a *game of kind* (who wins / controllability question) and a *game of degree* (optimal strategies / payoff value). For simple-motion players the game of kind admits geometric solutions via Voronoi diagrams and Apollonius circles [2]–[5], and a long line of work combines these geometric tools with Isaacs' (HJI) method: barrier curves for defending a circular region [6] revisited rigorously by Garcia et al. [7], [8]; multiplayer border defense in a compact convex *game region* via analytical barriers [9], [10]; dispersal surfaces in multiplayer border-defense games [11]–[13]; and reach-avoid under information asymmetry [14]. A parallel line treats perimeter defense where the target may have arbitrary convex shape but defenders are *constrained to move along the target boundary* [15]–[19]. The closest work, Pachter, Garcia & Casbeer [20], studies guarding a compact convex target set geometrically, but only for equal-speed players, identifies the barrier only for a circular target, and solves the game of degree only for a singleton (point) target.

## 3. Research Problem and Gap

**Problem.** The planar Two-Player Target-Defense Game (TPTDG): an evader $E$ attacks a compact, convex, *permeable* target set $\Omega := \{z=(x,y)\in\mathbb{R}^2 : h(z)\le 0\}$ with $h:\mathbb{R}^2\to\mathbb{R}$ convex and smooth, boundary $\partial\Omega = \{h(z)=0\}$ (eq. (1), p. 2); a pursuer $P$ tries to capture $E$ before $E$ enters $\Omega$. Both players have simple motion, $\dot{x}_P = v_P u_P$, $\dot{x}_E = v_E u_E$, $u_P, u_E \in \mathcal{U} = \{u\in\mathbb{R}^2 : \|u\|=1\}$ (eqs. (2)–(3)); joint dynamics $\dot{x} = f(x,u_P,u_E) = (v_P u_P, v_E u_E)$ (eq. (4)). Only the **slower evader** case $0<\gamma := v_E/v_P < 1$ is treated (p. 2). Information structure: "Both players are assumed to have complete information about each other's state and dynamics at every time instance" (p. 2). Termination: capture manifold $\mathcal{T}_c := \{x : (x_P = x_E) \wedge (x_E \notin \Omega)\}$, attack manifold $\mathcal{T}_a := \{x : x_E \in \Omega\}$, $t_f := \min(t_c, t_a)$ (p. 2). Capture game payoff $J_c = \mathrm{dist}(x_E(t_c), \Omega)$ — pursuer maximizes, evader minimizes (eq. (5), saddle condition (6), value $V_c = \min_{u_E(\cdot)}\max_{u_P(\cdot)} J_c$, eq. (7)); attack game payoff $J_a = \|x_E(t_a) - x_P(t_a)\|$ — pursuer minimizes, evader maximizes (eqs. (8)–(10)).

**[Authors' claim of the gap]** (p. 1): "All of the aforementioned references, however, only discuss the particular cases where the shape of the target set is simple (e.g., a point, line, or circle)"; in [20] "a barrier surface is only identified for a circular target case, and the game of degree is only solved for a singleton case"; in [15]–[19] "the defenders' motion is constrained along the target boundary". The main contribution claimed is "a complete solution to both the game of kind and the game(s) of degree of the planar TPTDG with any shape of compact convex target set with smooth boundary", explicitly generalizing "the solution framework and results in [7] specifically proposed for the circular target case": the proposed barrier function "takes a generalized form of (11) in [7]" and the feedback strategies are "in the generalized form of their counterparts in [7]" (p. 1).

**[Verified from cited text as printed in this paper]** The gap statement is consistent with the paper's own related-work paragraph: [6]–[13] are described as point/line/circular-target or game-region barriers, [15]–[19] as boundary-constrained perimeter defense, and [20] as same-speed geometric solution with circular barrier and singleton degree solution; I could only check these descriptions against what is printed in P098, not against the cited originals. The generalization claim relative to [7] is concrete and internally substantiated: the paper does deliver, for arbitrary compact convex smooth $\Omega$, the barrier of eq. (19) (replacing the circle-specific expression "(11) in [7]"), the winning sets (20)–(21), and both games of degree (Props. 4–5), so the claimed deliverables all exist in the paper. One caveat on completeness: the saddle-point *verification* is stationarity-only (see §5.5, §5.7), so "complete solution" is accurate at the level of the game of kind + candidate value/strategies, with the saddle inequalities (6)/(9) asserted rather than proven.

## 4. Core Contributions

1. **Theory (game of kind — generalized barrier)**: a barrier function on the joint state space $\mathbb{R}^4$, $B(\mathbf{x}; \Omega, \gamma) := \|\mathbf{Proj}_\Omega(C(\mathbf{x})) - C(\mathbf{x})\| - R(\mathbf{x})$ (eq. (19), Prop. 3), built from the Apollonius circle between the players and the **metric projection onto $\Omega$**; winning sets $\mathcal{R}_c := \{B > 0\}$ (capture), $\mathcal{R}_a := \{B \le 0\}$ (attack) (eqs. (20)–(21)); semipermeability of $\mathcal{B}$ (Remark 2). This is the "generalized Apollonius" barrier: for a circular target it reduces to the expression "(11) in [7]"; for a general $\Omega$ the distance from the Apollonius center to $\Omega$ is replaced by the distance to the projection $\mathbf{Proj}_\Omega(C)$.
2. **Theory (capture game of degree)**: continuously differentiable value $V_c(\mathbf{x}) = \|\mathbf{Proj}_\Omega(C(\mathbf{x})) - C(\mathbf{x})\| - R(\mathbf{x})$ over $\mathcal{R}_c$ (eq. (22)), unique optimal capture point $x^\star$ (eq. (24)), and unique state-feedback strategies (eq. (23), rewritten as (30)–(31)); no dispersal surface in $\mathcal{R}_c$ (Remark 3).
3. **Theory (attack game of degree)**: value $V_a(\mathbf{x}) = \|x^\dagger - x_P\| - \frac{1}{\gamma}\|x^\dagger - x_E\|$ (eq. (34)) where the optimal attack point $x^\dagger \in \partial\Omega$ is characterized as the global minimizer of a constrained optimization problem (eq. (35)), with unique state-feedback strategies (eq. (36)); no dispersal surface in $\mathcal{R}_a$ (Remark 4).
4. **Verification (theory)**: both candidate value/strategy pairs are shown to satisfy the stationary HJI equation $\nabla_{\mathbf{x}} V \cdot f(\mathbf{x}, u_P^\star, u_E^\star) = 0$ — eq. (33) for $V_c$ (after computing $\nabla_{\mathbf{x}} V_c$ in closed form, eqs. (26)–(29)) and eq. (38) for $V_a$ (gradient eq. (37)) — which the authors present as proof of the saddle-point property.
5. **Preliminary structural results**: Prop. 1 — under optimal play the controls are constant and trajectories are straight lines (Hamiltonian/co-state analysis, eqs. (11)–(13)); Remark 1 — distance-ratio invariance $\|x_E(t)-x_{E,0}\| = \gamma\|x_P(t)-x_{P,0}\|$; Definition 1 + Fact 1 — Apollonius circle geometry (eqs. (14)–(16)); Prop. 2 — dominant-region winning conditions (eqs. (17)–(18)), with ties on the Apollonius circle awarded to the evader.
6. **Numerical illustration (experiment)**: two scenarios (optimal play; one player deviating) on a non-circular quartic target, demonstrating linear optimal trajectories and the semipermeable crossing of the barrier under nonoptimal play (Figs. 1–2, Sec. V).

## 5. Key Mathematical Results

### 5.0 Model, information, termination, payoffs (pp. 2–3, eqs. (1)–(10))

Target $\Omega = \{h \le 0\}$, $h$ convex and smooth (eq. (1)); $\Omega$ **permeable** ("the pursuer can freely move in and out of the set if it is on his way to capture the evader", p. 2) — important: the pursuer is not blocked by $\Omega$. Simple motion (2)–(3) with $\mathcal{U} = \{u : \|u\| = 1\}$; joint state $\mathbf{x} = (x_P, x_E) \in \mathbb{R}^4$, $\dot{\mathbf{x}} = f(\mathbf{x}, u_P, u_E) = (v_P u_P, v_E u_E)$ (eq. (4)). Winning: $P$ wins iff $\mathbf{x}(t_f) \in \mathcal{T}_c$, $E$ wins iff $\mathbf{x}(t_f) \in \mathcal{T}_a$; capture requires $x_E \notin \Omega$, so **ties (simultaneous arrival) belong to the evader** (used crucially in Prop. 2/3). Capture-game payoff $J_c(\mathbf{x}_0, u_P(\cdot), u_E(\cdot)) = \mathrm{dist}(x_E(t_c), \Omega)$ (eq. (5)) with $\mathrm{dist}(x,S) = \inf_{y\in S}\|x-y\|$; because $\Omega$ is compact convex the infimum is attained at a unique point (p. 2). Saddle conditions as printed — eq. (6): $\min_{u_E^\star(\cdot)}\max_{u_P(\cdot)} J_c \le \min_{u_E^\star(\cdot)}\max_{u_P^\star(\cdot)} J_c \le \min_{u_E(\cdot)}\max_{u_P^\star(\cdot)} J_c$, and analogously eq. (9) for $J_a$ with $P$ as minimizer. Reading: the outer optima over the starred (fixed optimal) opponent strategy are vacuous, so (6) says exactly $\max_{u_P} J_c(u_P, u_E^\star) \le V_c \le \min_{u_E} J_c(u_P^\star, u_E)$ — the standard pair of saddle inequalities ($P$ cannot beat $V_c$ against optimal $E$; $E$ cannot undercut $V_c$ against optimal $P$). Values: $V_c = \min_{u_E}\max_{u_P} J_c$ (7), $V_a = \min_{u_P}\max_{u_E} J_a$ (10).

### 5.1 Proposition 1 (pp. 2–3, eqs. (11)–(13)): straight-line optimal play

**Statement**: for kinematics (2)–(3) and either payoff (5) or (8), "the players' optimal control inputs are constant over time and optimal trajectories are straight lines." **Proof approach**: Isaacs/Pontryagin Hamiltonian $\mathcal{H}(\lambda_P, \lambda_E, u_P, u_E) = v_P \lambda_P^\top u_P + v_E \lambda_E^\top u_E$ (eq. (11)); $\mathcal{H}$ is state-independent, so the canonical equations give $\dot{\lambda}_P^\star \equiv 0$, $\dot{\lambda}_E^\star \equiv 0$, i.e., constant costates $\bar{\lambda}_P, \bar{\lambda}_E \ne 0$; the Hamiltonian is separable in $(u_P, u_E)$, hence $\mathcal{H}(\bar{\lambda}_P, \bar{\lambda}_E, u_P^\star, u_E^\star) = \min_{\nu_E}\max_{\nu_P} \mathcal{H} = \max_{\nu_P}\min_{\nu_E}\mathcal{H} = \max_{\nu_P} v_P\bar{\lambda}_P^\top \nu_P + \min_{\nu_E} v_E \bar{\lambda}_E^\top \nu_E$ (eq. (12)); by Cauchy–Schwarz $u_P^\star(t) \equiv \bar{\lambda}_P/\|\bar{\lambda}_P\|$, $u_E^\star(t) \equiv -\bar{\lambda}_E/\|\bar{\lambda}_E\|$ (eq. (13)). **Decisive step**: separability + Cauchy–Schwarz in (12)–(13). **Scope**: proved for the capture game, "the analysis for the attack game can be done mutatis mutandis"; global in $[0, t_c]$; open-loop form (feedback versions derived later in Sec. IV). **Physical meaning**: optimal play = constant headings toward the (fixed) terminal point. **Remark 1** (p. 3): under optimal play $\|x_E(t) - x_{E,0}\| = \gamma \|x_P(t) - x_{P,0}\|$ for all $t \in [0, t_f]$ — the travel-distance ratio is fixed at $\gamma$, the property that makes all Apollonius reasoning valid.

### 5.2 Definition 1 (Apollonius Circle) and Fact 1 (p. 3, eqs. (14)–(16))

**Definition 1**: $\mathcal{A}(\mathbf{x};\gamma) := \{z \in \mathbb{R}^2 : \|z - C(\mathbf{x};\gamma)\| = R(\mathbf{x};\gamma)\}$ (eq. (14)) — the locus of points both players reach simultaneously under optimal (constant-input) play — with center and radius
$$C(\mathbf{x};\gamma) = \Big(\tfrac{1}{1-\gamma^2}(x_E - \gamma^2 x_P),\ \tfrac{1}{1-\gamma^2}(y_E - \gamma^2 y_P)\Big), \qquad R(\mathbf{x};\gamma) = \tfrac{\gamma}{1-\gamma^2}\sqrt{(x_E - x_P)^2 + (y_E - y_P)^2}$$
(eqs. (15)–(16)); $\gamma$ dropped from the arguments thereafter. (I verified (15)–(16) numerically: $\gamma = 0.5$, $x_P=(0,0)$, $x_E=(1,0)$ gives $C=(4/3,0)$, $R=2/3$, and $\|z - x_E\| = \gamma\|z - x_P\|$ on that circle.) **Fact 1** (stated without proof; all follow from (15)–(16) in one line): $\|C - x_E\| = \gamma R$, $\|C - x_P\| = R/\gamma$, hence $\|C - x_E\| = \gamma^2\|C - x_P\|$; capture game: the optimal capture point satisfies $\|x^\star - x_{E,0}\| = \gamma\|x^\star - x_{P,0}\|$ and $x^\star \in \mathcal{A}$ ($\|x^\star - C\| = R$); attack game: $\|x^\dagger - x_{E,0}\| = \gamma\|x_P(t_a) - x_{P,0}\|$.

### 5.3 Proposition 2 (p. 3, eqs. (17)–(18)): dominant regions and winning condition

**Dominant regions**: $\mathcal{D}_P(\mathbf{x};\gamma) := \{z \in \mathbb{R}^2 : \|z - C(\mathbf{x})\| > R(\mathbf{x})\}$ — *outside* the Apollonius circle (points $P$ reaches strictly faster) — and $\mathcal{D}_E(\mathbf{x};\gamma) := \{z \in \mathbb{R}^2 : \|z - C(\mathbf{x})\| \le R(\mathbf{x})\}$ — *inside, including* the circle $\mathcal{A} \subset \mathcal{D}_E$ (eqs. (17)–(18); the non-strict inclusion implements the ties-to-evader convention induced by $\mathcal{T}_c$). **Statement**: under optimal play, $P$ wins iff $\mathcal{D}_E \cap \Omega = \emptyset$; $E$ wins iff $\mathcal{D}_E \cap \Omega \ne \emptyset$. **Proof**: direct — if $\mathcal{D}_E \cap \Omega = \emptyset$ the pursuer reaches every point of $\Omega$ strictly faster; conversely a point of $\Omega$ reachable by $E$ at least as fast as $P$ lets $E$ terminate on $\mathcal{T}_a$ (if both arrive simultaneously the point lies on $\mathcal{A}$ and the joint state terminates at $\mathcal{T}_a$ by the definition of $\mathcal{T}_c$). Global, analytic, exhaustive (binary outcome — no portion of the state space left undetermined).

### 5.4 Proposition 3 + Remark 2 (pp. 3–4, eqs. (19)–(21)): the generalized barrier (game of kind)

**Statement**: with the orthogonal projection $\mathbf{Proj}_\Omega(x) := \arg\min_{z\in\Omega}\|z - x\|$ (exists and is unique for all $x$ because $\Omega$ is compact and convex, p. 3), the **barrier surface** dividing $\mathbb{R}^4$ into the winning sets is
$$\mathcal{B} = \{z \in \mathbb{R}^4 : B(z;\Omega,\gamma) = 0\}, \qquad B(\mathbf{x};\Omega,\gamma) := \|\mathbf{Proj}_\Omega(C(\mathbf{x})) - C(\mathbf{x})\| - R(\mathbf{x}) \quad (\text{eq. (19)}),$$
with winning sets $\mathcal{R}_c := \{z \in \mathbb{R}^4 : B(z;\Omega,\gamma) > 0\}$ (capture — $P$ guaranteed to win) and $\mathcal{R}_a := \{z \in \mathbb{R}^4 : B(z;\Omega,\gamma) \le 0\}$ (attack — $E$ guaranteed to win) (eqs. (20)–(21)). Explicitly flagged as "a generalized statement of Theorem 2 in [7]" (p. 3). **Proof approach**: $B > 0 \iff \|\mathbf{Proj}_\Omega(C) - C\| > R \iff \mathbf{Proj}_\Omega(C) \in \mathcal{D}_P \iff \mathcal{D}_E \cap \Omega = \emptyset$ (because $\mathbf{Proj}_\Omega(C) \in \Omega$ and it is the *closest* point of $\Omega$ to $C$, so all of $\Omega$ lies outside the closed disk $\mathcal{D}_E$), then invoke Prop. 2; $B \le 0$ gives $\mathbf{Proj}_\Omega(C) \in \mathcal{D}_E \cap \Omega \ne \emptyset$ and Prop. 2 again. **Decisive equation**: (19) itself — the comparison of the Apollonius radius against the distance from the Apollonius center to the target (through its projection). **Local/global**: global in $\mathbb{R}^4$; analytic given $\mathbf{Proj}_\Omega$; the cross-section of $\mathcal{B}$ at fixed $x_P$ (the *barrier curve* $\bar{\mathcal{B}}$) is visualizable in $\mathbb{R}^2$ (p. 4). **Physical meaning**: $R(\mathbf{x})$ is the evader's competitive reach around the Apollonius center; if even the nearest target point is farther than that reach, the evader can never touch $\Omega$. **Extensibility**: replaces the circle-to-circle distance in [7] by $\mathrm{dist}(C, \Omega)$ via projection — the same template extends to any target for which $\mathbf{Proj}_\Omega$ is available (convexity suffices for existence/uniqueness).

**Proof gap (printed typos, p. 4, left column, proof of Prop. 3 — verified on 600-dpi render)**: the printed proof contains two internally inconsistent set-inclusion phrases. (i) In the $B>0$ branch it prints: "it follows that $\mathbf{Proj}_\Omega(C(\mathbf{x})) \in \mathcal{D}_E$ and $\mathcal{D}_E \cap \Omega \ne \emptyset$, and thus … the pursuer is guaranteed to win" — this contradicts both the sentence immediately before it ("the exclusion $\mathbf{Proj}_\Omega(C(\mathbf{x})) \notin \mathcal{D}_E$ implies $\mathcal{D}_E \cap \Omega = \emptyset$") and Proposition 2; it should read "$\in \mathcal{D}_P$ and $\mathcal{D}_E \cap \Omega = \emptyset$". (ii) In the $B \le 0$ branch it prints "$\mathcal{D}_E \cap \Omega = \emptyset$" where it should read "$\ne \emptyset$" (the membership "$\in \mathcal{D}_E$" there is correct). Both *conclusions* ("pursuer is guaranteed to win" / "the evader will win under optimal play") and the proposition statement with (20)–(21) are the intended, correct ones; the errors are confined to these two phrases and the argument is repaired by the preceding sentence of the proof itself.

**Remark 2 (p. 4)**: $\mathcal{B}$ is **semipermeable** — "the state of the game $\mathbf{x}$ never crosses $\mathcal{B}$ under optimal play, but if either of the players deviates from his/her own optimal path, $\mathbf{x}$ could cross $\mathcal{B}$" (illustrated in Sec. V; the crossing time $t_s$ analysis is "omitted for brevity", p. 6).

### 5.5 Proposition 4 + Remark 3 (pp. 4–5, eqs. (22)–(33)): capture game of degree

**Statement**: over $\mathcal{R}_c$, the value function is
$$V_c(\mathbf{x}) = \|\mathbf{Proj}_\Omega(C(\mathbf{x})) - C(\mathbf{x})\| - R(\mathbf{x}) \quad (\text{eq. (22)}),$$
continuously differentiable on all of $\mathcal{R}_c$; the optimal state-feedback strategies are
$$u_P^\star = \frac{x^\star - x_P}{\|x^\star - x_P\|}, \qquad u_E^\star = \frac{x^\star - x_E}{\|x^\star - x_E\|} \quad (\text{eq. (23)}),$$
where the **optimal capture point** $x^\star = (x^\star, y^\star)$ is
$$x^\star = \Big(C_x + R(\mathbf{x})\tfrac{P_x - C_x}{\sqrt{(P_x - C_x)^2 + (P_y - C_y)^2}},\ \ C_y + R(\mathbf{x})\tfrac{P_y - C_y}{\sqrt{(P_x - C_x)^2 + (P_y - C_y)^2}}\Big) \quad (\text{eq. (24)}),$$
with $C(\mathbf{x}) = (C_x, C_y)$ and $\mathbf{Proj}_\Omega(C(\mathbf{x})) = (P_x, P_y)$ — i.e., $x^\star = C + R\,\frac{\mathbf{Proj}_\Omega(C) - C}{\|\mathbf{Proj}_\Omega(C) - C\|}$, the point of the Apollonius circle on the ray from the center toward the projected center. Note $V_c$ coincides in form with the barrier function $B$ of (19) but is now interpreted as the payoff value: the distance from the capture point to the target ("defense margin").

**Proof approach** (three steps): (i) *value identification*: from (7), $V_c = \min_{u_E^\star}\max_{u_P^\star} J_c = \mathrm{dist}(x^\star, \Omega)$; in $\mathcal{R}_c$, $x^\star \in \mathcal{A}$ and $\mathbf{Proj}_\Omega(C) \notin \mathcal{D}_E$, so $\|x^\star - C\| = R$ and $V_c(\mathbf{x}) = \|\mathbf{Proj}_\Omega(C) - C\| - R$ (eq. (25)). (ii) *Differentiability*: with the angles $\phi = \mathrm{atan2}(y_E - y_P, x_E - x_P)$ (elevation of $E$, equivalently of $C$, w.r.t. $P$) and $\theta = \mathrm{atan2}(P_y - C_y, P_x - C_x)$ (elevation of $x^\star$ w.r.t. $C$), the Jacobian and gradient are
$$\frac{\partial C(\mathbf{x})}{\partial \mathbf{x}} = \frac{1}{1-\gamma^2}\begin{bmatrix} -\gamma^2 & 0 & 1 & 0 \\ 0 & -\gamma^2 & 0 & 1\end{bmatrix} \ (26), \qquad \nabla_{\mathbf{x}} R(\mathbf{x}) = \frac{\gamma}{1-\gamma^2}\begin{bmatrix} -\cos\phi & -\sin\phi & \cos\phi & \sin\phi\end{bmatrix}^\top \ (27),$$
$$\nabla_{\mathbf{x}} V_c = -\Big[\frac{\partial C}{\partial \mathbf{x}}\Big]^\top \frac{\mathbf{Proj}_\Omega(C) - C}{\|\mathbf{Proj}_\Omega(C) - C\|} - \nabla_{\mathbf{x}} R = \frac{1}{1-\gamma^2}\begin{bmatrix} \gamma^2\cos\theta + \gamma\cos\phi \\ \gamma^2\sin\theta + \gamma\sin\phi \\ -\cos\theta - \gamma\cos\phi \\ -\sin\theta - \gamma\sin\phi \end{bmatrix} \ (\text{eqs. (28)–(29)}),$$
and since $0 < \gamma < 1$ and no state with $\|x_P - x_E\| = 0$ lies in $\mathcal{R}_c$, both angles are determinate, so $V_c \in C^1(\mathcal{R}_c)$. (iii) *HJI check*: the Isaacs equation "adjusted for our problem" is $-\partial V_c/\partial t = \nabla_{\mathbf{x}}V_c \cdot f(\mathbf{x}, u_P^\star, u_E^\star)$ (eq. (32)); $V_c$ is time-invariant, so the claim reduces to $\nabla_{\mathbf{x}}V_c \cdot v_P(u_P^\star, \gamma u_E^\star) = 0$, verified by substituting the angle-forms $u_P^\star = \big(R(\mathbf{x})\frac{\cos\phi + \gamma\cos\theta}{\gamma\|x^\star - x_P\|},\ R(\mathbf{x})\frac{\sin\phi + \gamma\sin\theta}{\gamma\|x^\star - x_P\|}\big)$ (eq. (30)) and $u_E^\star = \big(R(\mathbf{x})\frac{\gamma\cos\phi + \cos\theta}{\gamma\|x^\star - x_P\|},\ R(\mathbf{x})\frac{\gamma\sin\phi + \sin\theta}{\gamma\|x^\star - x_P\|}\big)$ (eq. (31), see typo below), giving eq. (33):
$$\nabla_{\mathbf{x}}V_c \cdot f = \frac{v_P R(\mathbf{x})}{1-\gamma^2} \begin{bmatrix}\gamma^2\cos\theta + \gamma\cos\phi \\ \gamma^2\sin\theta + \gamma\sin\phi \\ -\cos\theta - \gamma\cos\phi \\ -\sin\theta - \gamma\sin\phi\end{bmatrix} \cdot \begin{bmatrix}\frac{\cos\phi + \gamma\cos\theta}{\gamma\|x^\star - x_P\|} \\ \frac{\sin\phi + \gamma\sin\theta}{\gamma\|x^\star - x_P\|} \\ \frac{\gamma\cos\phi + \cos\theta}{\|x^\star - x_P\|} \\ \frac{\gamma\sin\phi + \sin\theta}{\|x^\star - x_P\|}\end{bmatrix} = 0.$$
**Decisive identity inside (33)** (my verification): with $A = \gamma\cos\theta + \cos\phi$, $A' = \gamma\sin\theta + \sin\phi$, $B = \cos\theta + \gamma\cos\phi$, $B' = \sin\theta + \gamma\sin\phi$, the first two components contribute $(A^2 + A'^2)/\|x^\star - x_P\|$ (using $\gamma^2\cos\theta + \gamma\cos\phi = \gamma A$) and the last two contribute $-(B^2 + B'^2)/\|x^\star - x_P\|$; since $A^2 + A'^2 = B^2 + B'^2 = 1 + \gamma^2 + 2\gamma\cos(\theta - \phi)$, the sum is exactly $0$ — the printed (33) is algebraically correct. I also verified (30) numerically ($\gamma=0.5$, $x_P = (0,0)$, $x_E=(1,0)$, singleton $\Omega$ at $(5,0)$: $x^\star = (2,0)$, $\phi = \theta = 0$, $u_P^\star = 1$). **Physical meaning**: under optimal play both players run straight to the fixed capture point; the predicted capture point is invariant along the optimal flow, hence $\dot V_c = 0$ along it. **Extensibility**: the template (open-loop solution → candidate feedback → HJI stationarity) is exactly the one transplanted from [7].

**Proof gap (scope of the saddle-point proof)**: eqs. (32)–(33) verify only *stationarity* of $V_c$ along the candidate saddle flow, i.e., $\nabla_{\mathbf{x}}V_c \cdot f(\mathbf{x}, u_P^\star, u_E^\star) = 0$. The inequalities required for a genuine HJI verification — $\nabla_{\mathbf{x}}V_c \cdot f(\mathbf{x}, u_P, u_E^\star) \le 0$ for all deviating $u_P$ and $\nabla_{\mathbf{x}}V_c \cdot f(\mathbf{x}, u_P^\star, u_E) \ge 0$ for all deviating $u_E$ (equivalently the printed saddle conditions (6)) — are never established. The saddle claim therefore rests on the geometric identification (Prop. 1 + Fact 1: straight-line play to the unique Apollonius capture point) plus stationarity, which is a standard but incomplete verification argument; the abstract's "proven to correspond to the saddle point solution of the game" (p. 1) overstates what is shown. A related gap: $\mathrm{dist}(x^\star, \Omega) = \|\mathbf{Proj}_\Omega(C) - C\| - R$ implicitly uses that $\mathbf{Proj}_\Omega(C)$ is also the unique nearest point of $\Omega$ to $x^\star$ (true for convex $\Omega$ by the projection variational inequality, but not proven in the paper).

**Typo (eq. (31), p. 5 — verified on 600-dpi render)**: as printed, $u_E^\star = R(\mathbf{x})\,\frac{\gamma\cos\phi + \cos\theta}{\|x^\star - x_P\|}$ (denominator without $\gamma$). Since $\|x^\star - x_E\| = \gamma\|x^\star - x_P\|$ (Fact 1), the unit vector is $u_E^\star = R(\mathbf{x})\frac{\gamma\cos\phi + \cos\theta}{\gamma\|x^\star - x_P\|}$; the printed expression equals $\gamma u_E^\star$ (norm $\gamma \ne 1$). Numerical check: same example as above gives printed value $1/2$ vs. correct $u_E^\star = (1,0)$. The HJI check (33) uses $\gamma u_E^\star = R(\mathbf{x})\frac{\gamma\cos\phi + \cos\theta}{\|x^\star - x_P\|}$, which matches the *corrected* form — so (31) is missing a factor $\gamma$ in the denominator while (30) and (33) are correct as printed.

**Remark 3 (p. 5)**: since $V_c$ is $C^1$ on $\mathcal{R}_c$, "there exists no dispersal surface in the capture set $\mathcal{R}_c$" and the optimal strategies "are always unique" there. (Note: absence of dispersal surfaces is inferred from smoothness of the value — a heuristic connection; uniqueness of the feedback is directly visible from (23)–(24) given uniqueness of $\mathbf{Proj}_\Omega$.)

### 5.6 Proposition 5 + Remark 4 (p. 5, eqs. (34)–(38)): attack game of degree

**Statement**: over $\mathcal{R}_a$,
$$V_a(\mathbf{x}) = \|x^\dagger - x_P\| - \tfrac{1}{\gamma}\|x^\dagger - x_E\| \quad (\text{eq. (34)}),$$
where $x^\dagger = (x^\dagger, y^\dagger) \in \partial\Omega$ is the **optimal attack point**, "the unique global minimizer of the following constrained convex optimization problem":
$$\text{minimize}_{z \in \mathbb{R}^2}\ -\|z - x_P\| + \tfrac{1}{\gamma}\|z - x_E\|, \qquad \text{subject to } h(z) = 0, \ \ \|z - x_E\| \le \gamma\|z - x_P\| \quad (\text{eq. (35)}).$$
$V_a$ is claimed $C^1$ on all of $\mathcal{R}_a$, and the optimal state-feedback strategies are
$$u_P^\star = \frac{x^\dagger - x_P}{\|x^\dagger - x_P\|}, \qquad u_E^\star = \frac{x^\dagger - x_E}{\|x^\dagger - x_E\|} \quad (\text{eq. (36)}).$$
(In (34)–(35) the symbols $x_P, x_E$ denote the initial positions $x_{P,0}, x_{E,0}$.) **Proof approach**: from (10) (as printed in the proof, with two minor typos: "$V_a(\mathbf{x}) = \min_{u_E^\star(\cdot)}\max_{u_P^\star(\cdot)} J_e$" — the min/max player roles are swapped w.r.t. (10) and the payoff is written $J_e$ instead of $J_a$) $V_a = \mathrm{dist}(x^\dagger, x_P(t_a))$; because optimal trajectories are straight lines, pursuer's travel distance to $t_a$ is $\frac{1}{\gamma}\|x^\dagger - x_E\|$, so the final separation is $\|x^\dagger - x_P\| - \frac{1}{\gamma}\|x^\dagger - x_E\|$ — eq. (34). The attack point maximizes the evader's final separation over the reachable arc of $\partial\Omega$ (the constraint in (35) is exactly $z \in \mathcal{D}_E$, i.e., points the evader reaches no later than the pursuer). **Gradient** (eq. (37)): with $\psi = \mathrm{atan2}(y^\dagger - y_P, x^\dagger - x_P)$ and $\varphi = \mathrm{atan2}(y^\dagger - y_E, x^\dagger - x_E)$ (elevations of $x^\dagger$ w.r.t. each player), $\nabla_{\mathbf{x}}V_a = \begin{bmatrix} -\cos\psi & -\sin\psi & (\cos\varphi)/\gamma & (\sin\varphi)/\gamma \end{bmatrix}^\top$; $\psi, \varphi$ always determinate since $\|x_E - x_P\| \ne 0$ for $t \in [0, t_a]$ (otherwise the game would have terminated). In angle form $u_P^\star = (\cos\psi, \sin\psi)$, $u_E^\star = (\cos\varphi, \sin\varphi)$. **HJI check** (eq. (38)):
$$\nabla_{\mathbf{x}}V_a \cdot f = \frac{v_P}{\gamma}\begin{bmatrix} -\gamma\cos\psi \\ -\gamma\sin\psi \\ \cos\varphi \\ \sin\varphi \end{bmatrix} \cdot \begin{bmatrix} \cos\psi \\ \sin\psi \\ \gamma\cos\varphi \\ \gamma\sin\varphi \end{bmatrix} = \frac{v_P}{\gamma}\big(-\gamma + \gamma\big) = 0.$$
**Decisive step**: the telescoping $-\gamma(\cos^2\psi + \sin^2\psi) + \gamma(\cos^2\varphi + \sin^2\varphi) = 0$. **Physical meaning**: in the attack region the evader picks the boundary point that maximizes the pursuer's final shortfall; the pursuer, doomed to lose, minimizes the same shortfall (heads to the attack point, ending at the closest reachable point $x_P(t_f)$). **Notation slip (eq. (38), p. 5 — verified on 500-dpi render)**: the $f$-vector inside (38) is written with the capture point $x^\star$ (star): $\frac{x^\star - x_P}{\|x^\star - x_P\|}, \frac{y^\star - y_P}{\|x^\star - x_P\|}, \gamma\frac{x^\star - x_E}{\|x^\star - x_E\|}, \gamma\frac{y^\star - y_E}{\|x^\star - x_E\|}$, where the attack-game point $x^\dagger$ (dagger) is meant; harmless for the value of the dot product but a copy-over from Prop. 4.

**Proof gap (convexity/uniqueness claim, eq. (35), p. 5)**: problem (35) is labeled a "constrained convex optimization problem", but (i) the objective $-\|z - x_P\| + \frac{1}{\gamma}\|z - x_E\|$ is a difference of Euclidean norms (concave + convex), hence not convex in general, and (ii) the feasible set $\{h(z) = 0\} \cap \mathcal{D}_E$ is an arc of the boundary curve, not a convex set. The asserted "unique global minimizer" is not proven: for elongated targets with several near-tangent boundary arcs, multiple local (even global) maximizers of the evader's final separation cannot be excluded a priori; no KKT or strict-concavity-on-the-arc argument is given. Uniqueness plausibly holds generically (e.g., strictly convex $\Omega$), but as printed this is an assumption in proposition clothing. The same stationarity-only caveat as in §5.5 applies to the saddle claim for the attack game.

**Remark 4 (p. 5)**: $V_a$ being $C^1$ on $\mathcal{R}_a$, "there exists no dispersal surface in $\mathcal{R}_a$", and the optimal strategies of both players "are always unique therein".

### 5.7 Consolidated verification status

- Game of kind: fully argued (Props. 2–3), modulo the two printed typos in the proof of Prop. 3 (§5.4); the barrier (19) is the paper's central object and is correct.
- Games of degree: value formulas (22), (34) are correct (both re-derivable in one line from Fact 1); feedback laws (23)/(24) and (36) are correct; the HJI stationarity checks (33), (38) are algebraically correct as printed (after noting the (31) $\gamma$-typo and the (38) star/dagger slip); the *saddle-point* inequalities (6)/(9) are never verified for deviating controls, and the convexity/uniqueness claim for (35) is unsubstantiated (§5.5, §5.6).
- Ties: the non-strict inclusion in (18) plus $\mathcal{T}_c$ requiring $x_E \notin \Omega$ give ties consistently to the evader throughout (Props. 2–3) — internally coherent modeling choice.

## 7. Limitations and Open Issues

**Author-stated**:
- Only the slower-evader case $0 < \gamma < 1$ is considered (p. 2); equal- and faster-evader cases are out of scope.
- Planar ($\mathbb{R}^2$), single pursuer vs. single evader, simple motion, complete information, permeable target (pp. 1–2).
- The crossing time $t_s$ analysis for barrier penetration under nonoptimal play is "omitted for brevity" (p. 6).
- Future work: "leverage the solution approach proposed herein to study the characteristics of barrier surfaces and optimal strategies in high-dimensional multiplayer target-defense games" (Sec. VI, p. 6).

**Critical observations (with page/eq. anchors)**:
1. **Printed typos in the proof of Prop. 3** (p. 4): the two set-inclusion phrases are swapped/garbled exactly as detailed in §5.4 — the $B>0$ branch prints "$\mathbf{Proj}_\Omega(C(\mathbf{x})) \in \mathcal{D}_E$ and $\mathcal{D}_E\cap\Omega \ne \emptyset$" before concluding the *pursuer* wins, and the $B\le0$ branch prints "$\mathcal{D}_E \cap \Omega = \emptyset$" before concluding the *evader* wins. The proposition statement (19)–(21) is correct; the proof text contradicts itself at these two points.
2. **Eq. (31) is not a unit vector as printed** (p. 5): missing factor $\gamma$ in the denominator (should be $\gamma\|x^\star - x_P\| = \|x^\star - x_E\|$); as printed it equals $\gamma u_E^\star$. Eqs. (30) and (33) are consistent with the corrected form (§5.5).
3. **Eq. (38) notation slip** (p. 5): uses $x^\star$ where the attack point $x^\dagger$ is meant (§5.6); the proof of Prop. 5 also opens with "$\min_{u_E^\star}\max_{u_P^\star} J_e$" — player roles swapped w.r.t. (10) and $J_e$ for $J_a$.
4. **Saddle-point verification is incomplete**: only stationarity $\nabla V \cdot f(\mathbf{x}, u_P^\star, u_E^\star) = 0$ is checked (eqs. (33), (38)); the saddle inequalities (6)/(9) for deviating controls are never established, despite the abstract's "proven to correspond to the saddle point solution" (p. 1). A full verification argument would additionally need the one-sided inequalities (or an equivalent semipermeability + terminal-payoff argument).
5. **"Constrained convex optimization" mislabel and unproven uniqueness of $x^\dagger$** (eq. (35), p. 5): difference-of-norms objective on a boundary arc; uniqueness of the global minimizer asserted, not proven (§5.6).
6. **Smoothness assumptions used but not fully discharged**: $V_c$'s $C^1$ claim (Prop. 4) presumes smooth dependence of $\mathbf{Proj}_\Omega(C)$ on $C$; with only "$h$ convex and smooth" (p. 2), boundary arcs that are flat (non-strictly convex) can make the distance term non-smooth at some $C$, so the blanket $C^1(\mathcal{R}_c)$ statement (and hence the "no dispersal surface" conclusion of Remark 3) needs a strict-convexity or $C^2$-regularity qualifier.
7. **Purely qualitative numerics**: no quantitative values of $V_c$/$V_a$, no timing, no platform, no comparison against HJI grid solutions or [7]/[20]; the barrier curve is "numerically computed" with the method unspecified (p. 5).
8. **Computational aspect of the attack game untouched**: implementing $u_E^\star$/$V_a$ requires solving (35) online (a nonconvex boundary optimization as printed); no algorithm, complexity, or real-time discussion is given.
9. **Ties-to-evader convention** is baked into (18) and $\mathcal{T}_c$; comparisons with literature where ties may be resolved differently should keep this in mind (p. 3).

## 8. Citation Value

**Paragraph role**: this is the reference that completes the "Isaacs + Apollonius geometry" program for target-defense games with *general* compact convex targets: it lifts the circular-region solution of Garcia–Casbeer–Pachter [7] to arbitrary smooth convex targets through one clean substitution — the distance from the Apollonius center to the circle is replaced by the distance to the metric projection $\mathbf{Proj}_\Omega(C)$ — and shows that the entire solution architecture (barrier → winning sets → value functions → unique feedback strategies → HJI stationarity → semipermeability) survives verbatim. It is the two-player backbone on which the same authors' later multiple-defender convex-target guarding work (e.g., Lee & Bakolas 2024, in this library) builds, and a natural baseline for any paper solving reach-avoid/target-defense games with non-circular targets (elliptical [Deng 2024], convex multi-defender, capture-the-flag regions). Cite it when (a) formulating a target-defense/reach-avoid game with a general convex target and needing the game-of-kind barrier; (b) using the capture/attack value functions (22)/(34) and feedback laws (23)/(36) as the saddle-point benchmark; (c) discussing generalized Apollonius constructions via projections; or (d) tracing the lineage of convex-target guarding games from Isaacs [1] through [7], [20] to the multiplayer extensions.

**Suggested citation sentences**: "Lee and Bakolas [P098] solve Isaacs' two-player target-defense game for a compact convex target set with smooth boundary by constructing the generalized Apollonius barrier $B(\mathbf{x};\Omega,\gamma) = \|\mathbf{Proj}_\Omega(C(\mathbf{x})) - C(\mathbf{x})\| - R(\mathbf{x})$, which partitions the joint state space into capture and attack winning sets, and derive $C^1$ value functions with unique state-feedback strategies for the capture and attack games of degree, verified against the Hamilton–Jacobi–Isaacs equation." Or, in a related-work sentence: "The convex-target guarding game has been solved in closed form for a single slower evader [P098], where the barrier surface is obtained by projecting the Apollonius center onto the target boundary; we extend this framework to [multiple defenders / elliptical targets / heterogeneous attackers]."

**Caveats when citing**: the PDF is the arXiv v2 preprint (no peer-reviewed venue printed; reported CDC 2021 version `to verify`); the saddle-point verification is stationarity-only and eqs. (31), (35) contain the imperfections documented in §5.5–§5.7 — cite the *statements* (Prop. 3–5), not the printed proofs, when precision matters.
