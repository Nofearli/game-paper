## 2. Research Background

Perimeter defense asks a set of defending vehicles to intercept mobile intruders before the intruders reach a protected boundary; it originates in Isaacs' target guarding formulation [5] and has since been studied as reach-avoid games [6]–[8] and border defense games [9], [10] (p. 1439). Practical motivators include deterring misused UAVs from restricted airspace, military applications, relaying critical information, and anti-poaching (p. 1439) [authors' claim]. The classical differential-game toolkit requires solving Hamilton–Jacobi–Bellman–Isaacs equations, which is tractable only for low-dimensional state spaces and simple environments [11], and most game-theoretic works assume a small, known set of intruders (p. 1439) [authors' claim]. This paper instead adopts the *competitive analysis* paradigm from online algorithms [26], [34]: the performance of a decentralized/cooperative online routing policy for the vehicles is compared, on the worst-case intruder release sequence, against an optimal offline (noncausal) algorithm that knows the entire release sequence in advance (p. 1439–1440). This is the journal generalization of the single-vehicle conical-environment analysis presented at CDC 2022 [33]; the key question is how the competitiveness frontier scales with the number of vehicles M (p. 1440).

## 3. Research Problem and Gap

**Problem.** In the planar conical environment E(θ) = {(y, α) : 0 < y ≤ 1, −θ ≤ α ≤ θ} (θ measured with respect to the y-axis, 0 < 2θ ≤ 2π), an arbitrary number of intruders is released at arbitrary time instants on the circumference y = 1; each intruder then moves radially inward with fixed speed v > 0 toward the protected region R(ρ, θ) = {(z, α) : 0 < z ≤ ρ < 1, −θ ≤ α ≤ θ}, whose boundary ∂R(ρ, θ) = {(y, α) : y = ρ, −θ ≤ α ≤ θ} is the perimeter (p. 1441). M > 1 identical vehicles, each a first-order integrator with unit speed and a finite capture radius r < ρ, must capture as many intruders as possible before they breach; capture occurs when an intruder lies within or on the radius-r capture circle of a vehicle at any instant (p. 1441). A problem instance is P(θ, ρ, v, r, M); an input sequence is I = {t, N(t), {(1, α₁), …, (1, α_{N(t)})}}ᵀ_{t=0} with arbitrary α_l ∈ [−θ, θ] (p. 1441). An online algorithm A assigns unit-magnitude velocities to all M vehicles at each time t as a function only of the revealed prefix I(t) ⊂ I; the optimal offline algorithm O has the entire sequence in advance (p. 1441). Performance is the total number of captured intruders; the competitive ratio is C_A(I, P) = n_O(I,P)/n_A(I,P) ≥ 1, c_A(P) = sup_I C_A(I, P), c(P) = inf_A c_A(P), and A is c-competitive if c_A(P) ≤ c (Definition 1, p. 1441). Analysis is restricted to inputs for which some offline algorithm captures at least one intruder (n_O(I,P) ≥ 1); if n_A(I,P) = 0 on some I, A is not c-competitive for any finite c (p. 1441). The stated objectives are: (1) establish a necessary condition for existence of online algorithms with finite competitive ratio, (2) design and analyze algorithms with provable guarantees, and (3) characterize the dependence of the competitive ratio on parameter regimes, especially M (p. 1441).

**Gap (with provenance).**
- Game-theoretic optimal-strategy approaches (reach-avoid [6]–[8], border defense [9], [10], perimeter-defense games with perimeter-constrained defenders [12], task assignment [14]–[16], sequential arrivals [17]) all "assume that some information about the intruders is known a priori" (p. 1440) [authors' claim], and optimal-strategy methods "do not scale with an arbitrary number of intruders released online" (p. 1440) [authors' claim].
- Stochastic/dynamic-vehicle-routing approaches ([21]–[23], building on [18]–[20]) "yield important insights into the average-case performance of defense strategies, [but] they do not account for the worst case in which intruders may coordinate their arrival to overcome the defense" (p. 1440) [authors' claim]; must-win search algorithms [24], [25] only detect every intruder and do not score partial capture (p. 1440).
- The authors' own conference paper [33] solved the single-vehicle conical case; the open question this journal paper answers is "how does the analytical bound on the competitiveness scale with multiple vehicles?" (p. 1440) [authors' claim].
- [my observation] No prior work cited in the paper performs a competitive (worst-case, arbitrary input) analysis of the multi-vehicle conical perimeter-defense problem; the M-dependence of both the fundamental limit and the achievable frontier is the specific novelty claimed.

## 4. Core Contributions

1. **Problem formulation (modeling)**: Perimeter defense with M > 1 identical finite-capture-radius vehicles in a conical environment under arbitrary (non-stochastic, non-anticipative) intruder releases, characterized by five parameters θ, v, ρ, r, M (p. 1440, 1441). The intruder set is fully adversarial; only the "at least one offline-capturable intruder" restriction is imposed (p. 1441).
2. **Necessary condition (theory)**: A fundamental limit — Theorem 5 (p. 1442) — giving a sharp condition on (θ, ρ, v, r, M) beyond which *no* online algorithm has a finite competitive ratio, via an explicit stream-plus-burst adversarial construction; plus Lemma 3 (optimal equal partition and vehicle placement) and Lemma 4 (stationary-capture radius threshold r ≥ ρ sin(θ/M)), the latter an improved lower bound over [33, Lemma III.1] (p. 1440, 1442).
3. **Decentralized algorithms (algorithm + theory)**: Partition of the environment into M equal dominance regions, each handled by a single-vehicle algorithm from [33]: Dec-Sweep, provably 1-competitive (Theorem 6, p. 1444); Dec-CaC, provably 2-competitive (Theorem 8, p. 1445); Dec-SNP, with parameter-dependent ratio (3n_s − 1)/2 (Theorem 10, p. 1445). Corollaries 7 and 9 prove equal-angle partitioning is optimal for the first two (p. 1444–1445).
4. **Cooperative algorithms (algorithm + theory)**: Coop-CaC, 1.5-competitive with an even number of vehicles (Theorem 15, p. 1447), and its odd-M variant, (M+1)/M-competitive (Remark 18, p. 1448); Coop-SNP, (3N − M)/(2M)-competitive for any M > 1 (Theorem 22, p. 1450), proved via a charging/accounting argument (Lemmas 19–21, Appendix p. 1453–1455); Corollary 23 shows Coop-SNP always dominates Dec-SNP in competitive ratio (p. 1450).
5. **Numerical regime synthesis and extensions (experiment/modeling)**: (v, M) and (v, ρ) parameter-regime plots comparing all five algorithms against the fundamental limit (Figs. 8–11, p. 1451–1452) and a competitive-ratio comparison (Fig. 12, p. 1452); an extension to heterogeneous capture radii (Section V-D, p. 1452–1453); and discussions of arbitrary convex perimeters and responsive intruders (p. 1453).

## 5. Key Mathematical Results

### 5.0 Dynamics, information structure, payoff, termination (p. 1441–1442)

- **Dynamics.** Vehicles: first-order integrators, unit speed (footnote 2: unit speed normalizes the scale; "speed of the intruders" and "speed ratio" v are used interchangeably). Footnote 1 states the work "can be extended to other models, such as double integrator" — left to future work. Intruders: released on y = 1, then radial inward motion at fixed speed v.
- **Information structure.** Online A sees only the revealed prefix I(t) (release times, counts, and locations after they occur); O is noncausal. The competitive analysis is interpreted as a game between the online player and an adversary who knows A and constructs the worst input [34] (p. 1441).
- **Capture / breach / winning conditions.** Capture: intruder within or on the capture circle (radius r, centered at a vehicle) at any instant; captured intruders are removed from E(θ). Breach: intruder reaches ∂R(ρ, θ) uncaptured (p. 1441). Payoff = total number of intruders captured; there is no time discount or terminal cost. Termination is at the end of the input horizon T (possibly infinite); ratios are sup/inf over input sequences (Definition 1, p. 1441).
- **Constraint on inputs.** Only I with n_O(I, P) ≥ 1 are considered; n_O ≥ n_A always; if n_A = 0 on some I then A is not c-competitive for any finite c (p. 1441).
- **Partition machinery.** Definition 2 (p. 1442): a partition of E(θ) is a set of q ≥ 1 unit-radius cones W_m with vertex at the origin, disjoint interiors, union E(θ) — the "dominance regions". Regions are numbered left-to-right (clockwise if θ = π); neighbors V_m, V_{m+1} share a "common boundary"; ∂R_m is the perimeter portion of W_m (p. 1442).

### 5.1 Lemma 3 (Optimal partition and placement) (p. 1442, eq. (1))

- **Statement**: For any problem instance P, positioning each vehicle V_m, 1 ≤ m ≤ M, at (ρ cos(θ/M), −(M − 2m + 1)(θ/M)) minimizes the distance (equivalently the time) from the vehicle's location to any location on ∂R_m.
- **Assumptions**: no two vehicles share an angular coordinate initially (so each is assigned one dominance region); regions numbered per Section 5.0.
- **Proof approach**: (i) within the mth region of angle 2β_m, the vehicle must sit on the angle bisector, i.e., at the midpoint of the chord L joining the two chord endpoints (ρ, ψ₁), (ρ, ψ₂), ψ₂ − ψ₁ = 2β_m (basic minimax geometry of a segment — the closest point to a set spanning the segment is its midpoint, and "at least one out of the two locations is shared by the neighbors"); (ii) neighbor equal-time condition at the shared endpoint: ρ sin(β_m) − r = ρ sin(β_{m+1}) − r, hence β_m = β_{m+1} (eq. (1)); (iii) eq. (1) over all m plus Σᵢ 2βᵢ = 2θ yields β_m = θ/M for all m — equal angles; (iv) the bisector angle gives α_m = −(M − 2m + 1)(θ/M); (v) trigonometric identities give x_m = ρ cos(θ/M).
- **Decisive equation**: eq. (1), ρ sin(β_m) − r = ρ sin(β_{m+1}) − r — the capture radius enters explicitly, which is what makes the equal partition the *radius-aware* optimum.
- **Local/global and type**: global (over all partitions and placements), analytic, exact.
- **Physical meaning**: the environment must be split into M equal cones and each vehicle parked on its cone's chord midpoint; this is the static configuration that minimizes worst-case response time to any perimeter point of the assigned sector.
- **Extensibility**: Section V-D (p. 1452–1453) states that with heterogeneous radii r₁, …, r_M the equal-time equations become M equations in the 2β_i whose solution replaces θ/M by β_i — a direct export path.
- **Proof gap**: none substantive; the "must be located at the midpoint of line L" step is asserted from Fig. 3 geometry rather than derived, but it is elementary.

### 5.2 Lemma 4 (Stationary capture threshold) (p. 1442)

- **Statement**: For any P with r ≥ ρ sin(θ/M), all intruders can be captured by keeping vehicle V_m stationary at (ρ cos(θ/M), −(M − 2m + 1)(θ/M)) ∀ 1 ≤ m ≤ M.
- **Assumptions**: M dominance regions of equal angle 2θ/M (Lemma 3).
- **Proof approach**: each region viewed as a single-vehicle conical environment; the result "follows analogously, as in [33, Lemma III.1]" — the chord midpoint at radius ρ cos(θ/M) is within distance ρ sin(θ/M) of every perimeter point of its region, so the capture disc covers ∂R_m entirely. Edge case: cos(θ/M) > 0 except when θ = π and M = 2 jointly hold; then a single vehicle at the origin with r ≥ ρ captures everything.
- **Local/global and type**: global; analytic; exact threshold. The paper notes this "improved lower bound" over [33, Lemma III.1] (p. 1442).
- **Consequence (standing assumption)**: r < ρ sin(θ/M) is assumed for the remainder of the paper (p. 1442) — everything beyond this lemma addresses the genuinely dynamic regime.
- **Proof gap**: the proof defers entirely to [33, Lemma III.1]; the one-line distance computation (max distance from (ρ cos(θ/M), ·) to ∂R_m equals ρ sin(θ/M)) is not spelled out [my observation].

### 5.3 Theorem 5 (Necessary condition for finite c(P)) (p. 1442–1444, eq. (2))

- **Statement**: For any problem instance P, let α = α* denote a solution of
  2 sin(θ − (M−1)α) − sin(α) − r/ρ = 0.
  Suppose further that
  v > (1 − ρ) / (2(ρ sin(θ − (M−1)α*) − r)), if 0 < α* < π/2;
  v > (1 − ρ)/(ρ − r), otherwise.
  Then there does not exist a c-competitive algorithm, for any finite c. (Verified at high resolution from p. 1442: there is **no square root** in the printed first case — the denominator is 2(ρ sin(θ − (M−1)α*) − r) = 2ρ sin(θ − (M−1)α*) − 2r.)
- **Assumptions**: both A and O start with all vehicles at the origin at time 0 (WLOG); inputs restricted to those with n_O ≥ 1; the adversary knows A.
- **Proof approach** (constructive adversarial input, three parts):
  1. *Input family* I = {I₁, …, I_M}: each I_l begins at time 1 with a **stream** — a single intruder at (1, θ) at every instant 1 + k(1−ρ)/v, k ∈ ℕ ∪ {0} (inter-arrival (1−ρ)/v = one intruder travel time to the perimeter), until time t, defined as the instant some vehicle captures a stream intruder; at time t a **burst** of c + 1 intruders is released at one of the M locations whose angular coordinates are the endpoints of the ∂R_m (excluding θ, including −θ); I₁ uses (1, −θ). If no vehicle ever captures the stream, the stream never ends while O captures all of it (one vehicle to (ρ, θ) at time 0) — result immediate. WLOG V_M captures the ith stream intruder at time t; since arrivals are (1−ρ)/v apart, "no online algorithm can capture more than 1 intruder from the stream" (p. 1443).
  2. *Best online positions at time t* (Fig. 4): O1 — V_M is on the chord of ∂R_M at distance r from (ρ, θ); O2 — V_M's time to the other chord endpoint equals V_{M−1}'s time to that endpoint; O3 — the other M−1 vehicles sit at their chord midpoints. Combining O1–O3: 2ρ sin(β) − 2r = ρ sin(α) − r, where 2β is W_M's angle and 2α each remaining region's angle, giving r/ρ = 2 sin(β) − sin(α); with 2(M−1)α + 2β = 2θ this yields f(α) := 2 sin(θ − (M−1)α) − sin(α) − r/ρ = 0 (eq. (2)). Existence of a root α*: f is continuous; f(ε) = 2 sin(θ − (M−1)ε) − r/ρ > 0 since 2 sin θ > r/ρ; f(θ/(M−1) − ε) = 2 sin ε − sin(θ/(M−1) − ε) − r/ρ < 0 for small ε; Intermediate Value Theorem gives a root in [ε, θ/(M−1) − ε]; α* is taken as the smallest root if several exist.
  3. *Ratio explosion*: **Case 1 (α* < π/2)**: the time for V_M to reach (ρ, θ − 2β) is 2ρ sin(θ − (M−1)α*) − 2r, and by O2–O3 the same is the time for any V_m (1 ≤ m < M) to reach an endpoint of its own ∂R_m; hence releasing the burst of c + 1 at time t defeats every vehicle if 2ρ sin(θ − (M−1)α*) − 2r > (1−ρ)/v, i.e., the burst breaches before anyone can reach its landing point. Moreover, any online algorithm that does *not* adopt the O1–O3 positions leaves some region W₁ with angle 2α₁ > 2α*, whence ρ sin(α₁) − r > ρ sin(α*) − r and the burst input targeted at that region still defeats it — so the construction covers all online algorithms. **Case 2 (α* ≥ π/2)**: possible only for M = 2 (for M > 2, (M−1)α* + β = θ ≤ π fails); the chord of W_{M−1} coincides with W_M's (θ = π) or lies outside the environment (θ < π), so V_{M−1}'s best position is the origin; ρ − r > (1−ρ)/v then prevents V_{M−1} from capturing the burst. Finally O, knowing everything, moves V_M to (ρ, θ) capturing all i stream intruders and one other vehicle to the burst angle τ_l capturing the c + 1 burst intruders: n_O(I) = i + c + 1, n_A(I) = 1, so C_A(I) = i + c + 1 > c for any finite c. ∎
- **Decisive equation/inequality**: eq. (2) and the burst-capture failure condition 2ρ sin(θ − (M−1)α*) − 2r > (1−ρ)/v (p. 1443), whose rearrangement is exactly the theorem's Case-1 threshold.
- **Local/global and type**: global (one construction defeats every online algorithm on its worst input); analytic; exact in the sense that it delineates the boundary beyond which finite competitiveness is impossible.
- **Physical meaning**: one vehicle is pinned by an endless stream at one extreme angle; while it is committed, the adversary dumps a burst at the far end of the partition, and if intruders are fast enough no redeployment can arrive in time. The threshold decreases as M grows (the curve in Figs. 8–11), quantifying the value of additional vehicles.
- **Extensibility**: Section V-D exports it to heterogeneous radii (time for V_i, i ≠ 1, to reach its endpoint is ρ sin(β_i) − r_i; for V₁ it is 2ρ sin(β₁) − 2r₁) (p. 1453); p. 1444 argues that using *two* streams does not tighten the bound (the burst must come after both streams are engaged, otherwise an online algorithm can keep the burst from ever arriving and retain a finite ratio).
- **Proof gaps**: [my observation] (i) the identification "the same expression represents the time taken by any vehicle V_m, 1 ≤ m < M, to reach an endpoint of ∂R_m" (p. 1443) relies on O2/O3 but the exact placement of V_m relative to *which* endpoint (distance ρ sin α − r vs. r) is not written out; Fig. 4 is the only supporting illustration. (ii) The "stream arrival every 1 − ρ/v time units apart" phrase on p. 1443 is a misprint for (1−ρ)/v, as the constructed release times 1 + k(1−ρ)/v show. (iii) The claim that O captures "all i intruders" assumes O can be at (ρ, θ) exactly when stream intruders arrive — valid since consecutive arrivals are (1−ρ)/v apart and O is noncausal.

### 5.4 Theorem 6 (Dec-Sweep is 1-competitive) (p. 1444) and Corollary 7 (p. 1444–1445)

- **Statement (Theorem 6)**: Algorithm Decentralized Sweep is 1-competitive, c^Dec-Sweep = 1, for any P satisfying
  v ≤ min{ 2rM/(4θ(ρ + r)), M(1 − ρ)/(4θ(1 − r)) },
  with radial location x_S^m = min{1 − r, ρ + r} ∀ m ∈ {1, …, M}, where x_S^m ∈ [ρ − r, min{1 − r, ρ + r}] is the sweep radius. Otherwise Dec-Sweep is not c-competitive for any constant c.
- **Proof outline** (only an outline is given, p. 1444): (i) each dominance region of angle 2θ/M is a single-vehicle conical environment, so the sweep analysis of [33] applies per region; (ii) every intruder is captured provided v ≤ M(x_S + r − ρ)/(4θ x_S) holds in every W_m; (iii) M(x_S + r − ρ)/(4θ x_S) is monotonically increasing in x_S, so the best choice is the largest admissible x_S = min{1 − r, ρ + r}; substituting both branches of the min gives exactly the two printed terms (x_S = ρ + r gives 2rM/(4θ(ρ + r)); x_S = 1 − r gives M(1 − ρ)/(4θ(1 − r))).
- **Statement (Corollary 7)**: Partitioning the environment into dominance regions of equal angles maximizes the speed ratio for which Theorem 6 holds.
- **Proof approach** (contradiction): suppose two regions have angles 2γ₁ < 2γ₂; equal sweep times are forced (otherwise the adversary concentrates input in the slowest region): 4γ₂x_S² = 4γ₁x_S¹, so x_S¹ = x_S² γ₂/γ₁; the worst-case 1-competitiveness requirement becomes v ≤ min{(x_S² + r − ρ)/(4γ₂x_S²), (x_S¹ + r − ρ)/(4γ₁x_S¹)} = (x_S² + r − ρ)/(4γ₂x_S²); since x_S² < x_S¹ and x_S¹ = min{1 − r, ρ − r} [as printed — likely a misprint for min{1 − r, ρ + r} of Theorem 6, my observation], the requirement can be relaxed by increasing γ₁ until γ₁ = γ₂. ∎
- **Decisive inequality**: v ≤ M(x_S + r − ρ)/(4θ x_S) (per-region capture condition, p. 1444) and its monotonicity in x_S.
- **Local/global and type**: global; analytic; exact (ratio 1 is the best possible).
- **Physical meaning**: with enough vehicles, back-and-forth sweeping of each equal cone captures *every* intruder — the online algorithm matches the offline optimum — provided intruders are slow enough; the threshold grows linearly in M (Figs. 8–9).
- **Extensibility**: p. 1453 states the fundamental limit (Theorem 5) and the decentralized sweep algorithm "apply as is" when intruders are responsive (can move in any direction) [authors' claim].
- **Proof gaps**: Theorem 6 has only a proof outline referencing [33]; the per-region sweep condition v ≤ M(x_S + r − ρ)/(4θ x_S) is imported from [33] without restatement [my observation]. The Corollary 7 misprint noted above.

### 5.5 Theorem 8 (Dec-CaC is 2-competitive) (p. 1445, eq. (3)) and Corollary 9

- **Statement (Theorem 8)**: If
  v ≤ min{ Mr/(θ(ρ + r)), M(1 − ρ)/((2 − 3r + ρ)θ), M(1 − ρ)/(θ(ρ − r)) }  (eq. (3))
  holds, then for all m ∈ {1, …, M}, with x_C^m = min{ρ + r, M(1 − r)/(M + vθ)} (with x_C^m ∈ [ρ − r, min{ρ + r, M(1−r)/(M+vθ)}]), Algorithm Dec-CaC is 2-competitive.
- **Proof**: "As the proof is analogous to that of Theorem 6, we omit the proof for brevity" (p. 1445) — the full proof is **not in the paper** [my observation: this is the weakest-documented of the constant-ratio results; all three bounds are asserted by analogy].
- **Corollary 9**: equal-angle partitioning maximizes the speed ratio for which Theorem 8 holds; proof omitted as analogous to Corollary 7.
- **Type**: global; analytic. Physical meaning: compare-and-capture trades a factor-2 loss (it deliberately concedes one of two angular sets per epoch) for a strictly larger admissible speed regime than Dec-Sweep — e.g., the first term Mr/(θ(ρ+r)) is twice Dec-Sweep's 2rM/(4θ(ρ+r)) [my observation, by term-by-term comparison of Theorem 6 and eq. (3)].
- **Proof gap**: the entire proof; the reader must reconstruct it from [33].

### 5.6 Theorem 10 (Dec-SNP competitiveness) (p. 1445)

- **Statement**: For any P satisfying 3D ≤ (1 − ρ)/v,
  c^Dec-SNP = (3n_s − 1)/2, where n_s = ⌈θ/(Mθ_s)⌉, θ_s = arcsin(r/ρ), and D = 2ρ cos(θ_s) sin((n_s − 1)θ_s).
- **Mechanism (p. 1445)**: each of the M equal dominance regions is further divided into n_s sectors; Dec-SNP positions the vehicle at distance ρ cos(θ_s) from the origin (the Lemma-4 resting geometry with sector half-angle θ_s = arcsin(r/ρ)) in a specific sector, i.e., the vehicle guards one sector's perimeter at a time and relocates across sectors of its own region.
- **Interpretation**: n_s is the number of radius-r sectors needed to tile a 2θ/M cone; the ratio (3n_s − 1)/2 is counting-based: per 3 intruder "time slots", the vehicle defends its own sector (2 slots) while n_s − 1 other sectors in its region go undefended. Note D has no π/2 cap because (n_s − 1)θ_s < θ/M ≤ π/2 for M ≥ 2, θ ≤ π [my observation — this is why only Coop-SNP's D̃ in eq. (5) needs the cap].
- **Proof**: "using an argument analogous to that for establishing Theorem 6" (p. 1445) — not given in full.
- **Type**: global; analytic; the ratio is exact for the stated counting argument but tightness is not established [my observation]. Physical meaning: works when the perimeter is small or the capture radius relatively large (few sectors), including regimes where Dec-Sweep/Dec-CaC are ineffective (small r, large ρ, p. 1445).
- **Consistency check [my observation]**: for n_s = 1 the ratio is 1 and D = 0 — matching Lemma 4's stationary capture when M ≥ θ/θ_s; Fig. 11's "Dec-SNP is 2.5-competitive for 0.15 ≤ ρ ≤ 0.26" corresponds to n_s = 2. Both check out.

### 5.7 Coop-CaC machinery: Definitions 11–12, set definitions, eq. (4) (p. 1445–1446)

- **Setup**: requires M even. Partition E(θ) into M/2 dominance regions of angle 4θ/M; each W_m into three equal sectors of angle 4θ/(3M) (Fig. 5); vehicles V₁^m, V₂^m are assigned to sectors {1,2} and {2,3} respectively, sharing the middle sector — this overlap is what beats Dec-CaC's ratio (p. 1445).
- **Definition 11 (Angular path, p. 1446)**: T_s^m(x_C^{s,m}, β_{s,m}, β̄_{s,m}) := {(x_C^{s,m}, β) : β_{s,m} ≤ β ≤ β̄_{s,m}} — a circular arc at the vehicle's fixed radius x_C^{s,m}. Completing the motion means traversing the arc twice (out and back); the completion time is 2(β̄_{s,m} − β_{s,m}) x_C^{s,m}.
- **Definition 12 (Epoch, p. 1446)**: an epoch is the time interval of length 2(β̄ − β)x_C during which all vehicles execute one full angular-path motion. In every epoch β̄_{s,m} − β_{s,m} = 4θ/(3M), so **every epoch has length (8θ/(3M)) x_C^{s,m}** (p. 1447).
- **Admissible radii**: x_C^{s,m} ∈ (ρ − r, min{ρ + r, 3M(1−r)/(3M + 4θv)}]; the upper branch comes from x_C + r + (4θ/(3M)) v x_C ≤ 1 (must still catch intruders released at y = 1 by epoch end). Non-emptiness requires ρ − r < 3M(1 − r)/(3M + 4θv), i.e., **v < 3M(1 − ρ)/(4θ(ρ − r))** (eq. (4), p. 1446).
- **Sets (epoch k, p. 1446)**: with φ measured as angular offset within the vehicle's two-sector span [0, 4θ/(3M)] (right side) or [−4θ/(3M), 0) (left side),
  R_k^{s,m} := {(y, φ) : ρ + φ x_C^{s,m} v < y ≤ min{1, x_C^{s,m} + r + (8θ/(3M) − φ) v x_C^{s,m}}},
  L_k^{s,m} := {(y, φ) : ρ − φ x_C^{s,m} v < y ≤ min{1, x_C^{s,m} + r + (8θ/(3M) + φ) v x_C^{s,m}}},
  and I_m^k ≜ R_{1,m}^k ∩ L_{2,m}^k (the middle-sector overlap). [Verified from the rendered page: the lower bounds are ρ ± φ x_C v — product with v; the upper bounds use the *last-visit* time (8θ/(3M) ∓ φ) x_C.] Interpretation: an intruder in R_k^{s,m} (resp. L_k^{s,m}) will be captured while V_s^m traverses its angular path: the lower bound guarantees it has not yet breached when the vehicle first sweeps its angle (first-visit time φ x_C), the upper bound guarantees capture by the final visit (last-visit time (8θ/(3M) − φ) x_C) [my reconstruction, consistent with Definition 11's out-and-back motion].
- **Algorithm 1 (p. 1447)**: at each epoch, compare |L_{1,m}^k|, |R_{2,m}^k|, |I_m^k|. Case 1 (|I_m^k| is a maximum): the two vehicles jointly take I and the richer of the other two sets, both moving the same direction, with β_{s,m} = φ₁ − 4θ/(3M), β̄_{s,m} = φ₁ (counterclockwise) or β_{s,m} = φ₁, β̄_{s,m} = φ₁ + 4θ/(3M) (clockwise), where φ₁ = −((3/2)(M − 4(m−1)) − 2s)·2θ/(3M) is measured from the positive y-axis (verified from rendered page). Case 2: each vehicle individually picks the richer of its two sets (V₁^m: L_{1,m}^k vs I_m^k; V₂^m: R_{2,m}^k vs I_m^k) with the corresponding direction assignment (explicit formulas, p. 1447).

### 5.8 Lemma 13 and Corollary 14 (no-intruder-left-behind conditions) (p. 1447)

- **Statement (Lemma 13)**: Any intruder in W_m at a radial location exceeding x_C^{s,m} + r + (8θ/(3M) − φ) v x_C^{s,m} ∀φ ∈ [0, 4θ/(3M)] and for any s ∈ {1,2} at the start of epoch k is contained in R_{s,m}^{k+1} or L_{s,m}^{k+1} in epoch k + 1 and does not breach the perimeter in epoch k, if
  v ≤ 3M(x_C^{s,m} + r − ρ)/(8θ x_C^{s,m}).
- **Proof approach**: WLOG s = 2 with |I_m^k| < |R_{2,m}^k|; (i) epoch length is (8θ/(3M)) x_C^{2,m}; (ii) the worst-case not-yet-considered intruder sits just above (x_C^{2,m} + r + (4θ/(3M)) v x_C^{2,m}, φ₁ + 4θ/(3M)) at epoch start (the extreme of the set boundary at φ = 4θ/(3M)); (iii) when the vehicle reaches (x_C^{2,m}, φ₁ + 4θ/(3M)) that intruder is just above (x_C^{2,m} + r, φ₁ + 4θ/(3M)) and is not captured; (iv) under the v bound, at epoch end it is still at least (4θ/(3M)) v x_C away from the perimeter — indeed its radius x_C + r + (4θ/(3M)) v x_C − v(8θ/(3M)) x_C exceeds ρ exactly when v ≤ 3M(x_C + r − ρ)/(8θ x_C) — so it enters the epoch-(k+1) sets.
- **Corollary 14**: any intruder beyond I_m^k in epoch k lands in I_m^{k+1} if the Lemma-13 bound holds (applies the lemma to both vehicles).
- **Type**: global (per dominance region); analytic; this is the induction step that makes the per-epoch counting valid forever.
- **Proof gap** [my observation]: step (iii)'s "will not be captured" is argued by the worst-case "just above x_C + r" placement at the single visit instant; capture by the disc while the vehicle sweeps *between* the two visit angles is handled only implicitly through the set definitions (which use the last-visit time in the upper bound). The argument is correct for the printed set definitions but terse.

### 5.9 Theorem 15 (Coop-CaC is 1.5-competitive) (p. 1447–1448)

- **Statement**: c^Coop-CaC = 1.5 for any P satisfying v ≤ min_{m ∈ {1,…,M}} {3M(x_C^{s,m} + r − ρ)/(8θ x_C^{s,m})} and eq. (4), for any x_C^{s,m} ∈ [ρ − r, min{ρ + r, 3M(1−r)/(3M + 4θv)}]. [The min is printed over m ∈ {1, …, M} although only M/2 regions exist — likely a misprint for {1, …, M/2}, my observation; the proof works "for any W_m, m ∈ {1, …, M/2}".]
- **Assumptions**: M even; Lemma 13 + Corollary 14 conditions (every intruder eventually enters the considered sets); offline O assumed to capture everything.
- **Proof approach** (per-epoch 3-case counting in one W_m; independence across regions):
  - Notation: r₂, l₁, l₂ + r₁ intruders in R_{2,m}^k, L_{1,m}^k, I_m^k.
  - **Case 1** (|I| ≥ |L₁| and |I| ≥ |R₂|): the algorithm's conditions r₁ + l₂ ≥ l₁ and r₁ + l₂ ≥ r₂ hold; WLOG l₁ ≥ r₂; the pair captures r₁ + l₂ + l₁ out of r₁ + l₂ + l₁ + r₂; c = (r₁ + l₂ + l₁ + r₂)/(r₁ + l₂ + l₁) ≤ 3r₂/2r₂ = 1.5, using denominator ≥ 2r₂ (from r₁ + l₂ ≥ r₂ and l₁ ≥ r₂).
  - **Case 2** (|I| < |L₁| and |I| ≥ |R₂|): conditions r₁ + l₂ < l₁, r₁ + l₂ ≥ r₂; same counts; same bound 3r₂/2r₂ = 1.5. (The mirrored case |I| ≥ |L₁|, |I| < |R₂| is omitted as analogous.)
  - **Case 3** (|L₁| > |I| and |R₂| > |I|): conditions r₁ + l₂ < l₁ and r₁ + l₂ < r₂; the vehicles capture l₁ + r₂ out of the total; c = (r₁ + l₂ + l₁ + r₂)/(r₂ + l₁) ≤ 3(r₁ + l₂)/(2(r₁ + l₂)) = 1.5, using r₂ + l₁ ≥ 2(r₁ + l₂) from the two conditions.
  - Hence each region captures ≥ 2/3 of its arrivals per epoch; summing over independent regions and invoking Lemma 13/Corollary 14 (every intruder is eventually considered) yields exactly c^Coop-CaC = 1.5.
- **Decisive inequality**: per-case denominator lower bound (e.g., r₂ + l₁ ≥ 2(r₁ + l₂)), which converts the set-overlap geometry into the constant 3/2.
- **Local/global and type**: global; analytic; exact constant for the algorithm; whether 1.5 is the best achievable by *any* online algorithm in this regime is open [my observation].
- **Physical meaning**: two vehicles sharing a middle sector lose at most one of every three intruders in the worst epoch; the price is a 3/4-times smaller speed regime than Dec-CaC (Remarks 16–17).
- **Remark 16 (p. 1448)**: since 3M(x_C + r − ρ)/(8θ x_C) is monotonically increasing in x_C, placing vehicles at min{ρ + r, 3M(1−r)/(3M + 4vθ)} gives the explicit regime v ≤ min{ 3Mr/(4θ(ρ + r)), 3M(1 − ρ)/(4θ(2 − 3r + ρ)), 3M(1 − ρ)/(4θ(ρ − r)) }.
- **Remark 17 (p. 1448)**: "The maximum speed ratio for which Algorithm Coop-CaC is effective is 3/4-th of the maximum speed ratio for which the Dec-CaC algorithm is effective" — each term of Remark 16 is exactly 3/4 of the corresponding term of eq. (3) [verified term-by-term, my observation].
- **Remark 18 (Modified Coop-CaC, p. 1448)**: for odd M, partition E(θ) into M + 1 sectors each of angle 2θ/(M+1) and position vehicles so R_m^k and L_{m+1}^k overlap for all m ∈ {1, …, M − 1} (Fig. 6); following the Coop-CaC steps it "can be shown" the algorithm is (M+1)/M-competitive; its v-bound is lower than Coop-CaC's (more overlap); c^Modified-CaC < c^Coop-CaC for M > 2 and equality at M = 2. **Not formally established** ("omit establishing the result formally due to space constraints") — proof gap [my observation: the claim c^Mod < c^Coop for M > 2 is plausible since (M+1)/M < 1.5 iff M > 2, but no accounting proof is provided].

### 5.10 Coop-SNP: construction, Lemmas 19–21, Theorem 22, Corollary 23 (p. 1448–1450, Appendix p. 1453–1455)

- **Construction (p. 1448–1449)**: divide E(θ) directly into N = ⌈θ/θ_s⌉ sectors δ₁, …, δ_N each of angle 2θ_s = 2 arcsin(r/ρ); requires M < N (if M ≥ N, assigning one vehicle per sector captures everything, ratio 1). Resting point of δ_l: (x_l, α_l) := (ρ cos(θ_s), (l − (N+1)/2) 2θ_s) — from Lemma 4, the position whose radius-r disc covers all of ∂R_l. Let
  D̃ = 2ρ cos(θ_s) sin((N − 1)θ_s), if (N − 1)θ_s < π/2;  2ρ cos(θ_s), otherwise  (eq. (5))
  — the distance between the two furthest-apart resting points (chord length, capped at the diameter). Time is slotted into intervals of length D̃ (the jth interval [(j − 1)D̃, jD̃]); since intruders traverse the radial gap at speed v, each slot corresponds to a radial band of thickness D̃ v; finite competitiveness requires **(1 − ρ)/v ≥ 3D̃** (three slots of lookahead between release radius and perimeter). S_l^j = set of intruders arriving in sector δ_l during slot j.
- **Algorithm 2 (p. 1449)**: at decision instants 3D̃ + 2jD̃: (S1, Comparison) compute η_i^L = |S_i^{j+2}| + |S_i^{j+3}| if i ∉ L (L = sectors currently occupied), else |S_i^{j+1}| + |S_i^{j+2}| + |S_i^{j+3}|; select the top-M sectors (ties broken as in Dec-SNP). (S2, Assignment) vehicles already at selected sectors (Õ ⊆ O with vehicles Ṽ) stay 2D̃; for the remaining sectors Ô = O \ Õ (ordered by decreasing |S_q^{j+2}|) and free vehicles V̂ (ordered increasing by |S_p^{j+1}| of their current sectors): (ii-a) if |S_q^{j+2}| > |S_p^{j+1}|, send V_p to δ_q for 2D̃ (arriving within D̃); (ii-b) otherwise keep V_p at δ_p for D̃ (capturing S_p^{j+1}) then move to δ_q for the next D̃ (capturing S_q^{j+2}). Epoch length is fixed 2D̃. Initialization: at time 0 each V_i rests at δ_i for D̃; first iteration at 3D̃ with dummy empty S^{j+1}, S^{j+2}.
- **Lemma 19 (p. 1450)**: for any j ≥ 1, every vehicle V_m ∈ V assigned sector δ_i captures at least one of S_m^{j+1}, S_i^{j+2} within [jD̃, (j+2)D̃]. Proof: case analysis over the three assignment modes (stay: captures both; (ii-a): captures S_i^{j+2} after relocating; (ii-b): captures S_m^{j+1} before relocating). Trivial but load-bearing.
- **Lemma 20 (p. 1450; proof in Appendix p. 1454)**: under Coop-SNP, for each vehicle, every two consecutive captured sets are **charged at most 3(N − M) times**. Proof approach: an accounting/charging scheme where each captured set pays for the breached sets considered in the same comparison S1; since exactly |L′| = N − M sectors are unoccupied, the four possible types of consecutive captured-set pairs (Fig. 13, p. 1452) are charged (type 1) 2(N − M), (types 2–4) 3(N − M) — each type's charges enumerated over the breached sets S_l^{j+1}, …, S_l^{j+5}, δ_l ∈ L′.
- **Lemma 21 (p. 1450; proof in Appendix p. 1454–1455)**: every breached set is accounted for (charged) by captured sets. Proof approach: a Coop-SNP run is decomposed into per-vehicle "vehicular traces" {k₁, …, k_N} (intervals spent capturing at each sector's resting point); any trace is a concatenation of five atomic traces — (i) k_i = 3, k_l = 0 ∀δ_l ∈ L′; (ii) k_i = 3, k_o = 1; (iii) k_i = 2, k_o = 1; (iv) k_i = 1, k_o = 1 (two subcases); (v) k_i = 0, k_o = 1 — and for each, the η-comparison inequalities (η_i^L ≥ η_p^L etc.) at times 2jD̃ are shown to imply that the sets actually captured dominate the sets breached (e.g., in case (ii), since S_o^{j+4} < S_i^{j+3}, capturing S_i^{j+3} and S_o^{j+5} accounts for S_p^{j+4}, S_p^{j+5}, S_i^{j+3}, S_i^{j+4}, S_i^{j+5}). Boundary slots are handled with dummy zero-cardinality sets S_i^0 and S_i^{Y+1} (Y = last nonempty slot).
- **Theorem 22 (p. 1450)**: The Coop-SNP algorithm is **(3N − M)/(2M)-competitive** for any P satisfying 3D̃ ≤ (1 − ρ)/v, with N = ⌈θ/θ_s⌉, θ_s = arcsin(r/ρ), D̃ per eq. (5).
  Proof: Lemma 20 — every two consecutive captured sets (2 per vehicle) pay for ≤ 3(N − M) breached sets; over M vehicles the total set count is 3(N − M) + 2M = 3N − M; Lemma 21 — every breached set is charged; assuming O captures every set, c = (3N − M)/(2M). ∎
- **Corollary 23 (p. 1450)**: c^Coop-SNP ≤ c^Dec-SNP for any P. Proof: need (3n_s − 1)/2 ≥ (3N − M)/(2M) ⟺ n_s ≥ N/M; write θ/θ_s = M + p with p ≥ 1 (integer N > M): Case 1 (θ/θ_s integer): n_s = ⌈1 + p/M⌉ ≥ 1 + p/M = N/M. Case 2 (non-integer): n_s = ⌈1 + (p − 1 + ε)/M⌉ for some 0 < ε < 1; if p ≤ M then ⌈1 + (p−1+ε)/M⌉ ≥ 1 + p/M; if p > M write p/M = q + l/M with q ∈ ℤ⁺, 0 < l < M, reducing to the same expression. ∎
- **Type**: global; analytic; the ratio is a worst-case accounting bound; tightness not established [my observation].
- **Physical meaning**: with N sectors and only M vehicles, N − M sectors are always exposed; the slotting (three slots of intruder flight time) lets each vehicle defend one sector per two slots while the charges spread the exposed sectors' losses over the captures — the ratio (3N − M)/(2M) → 1 as M → N and grows linearly in N.
- **Remark 24 (p. 1450)**: for UAVs at different altitudes no collision avoidance needed; otherwise D̃ must be scaled to include relocation overhead; the competitive-ratio bound is unaffected as long as 3D̃ ≤ (1 − ρ)/v holds, since the ratio does not depend on D̃.
- **Remark 25 (p. 1450)**: cooperative algorithms achieve lower ratios than their decentralized counterparts but require slower intruders — equivalently, more vehicles to cover the same (v, ρ) regime.
- **Proof gaps** [my observation]: (i) Lemma 20's type-1 charge is 2(N − M) < 3(N − M), so the lemma's "at most" is correct but the theorem's count 3(N − M) + 2M silently uses the worst type; (ii) the atomic-trace decomposition in Lemma 21 asserts every trace decomposes into the five cases without a formal induction; (iii) Algorithm 2 line 9 uses |S_q^{j+2}| ≥ |S_p^{j+1}| while the S2(ii-a) text on p. 1449 uses strict > — an immaterial but real inconsistency.

## 7. Limitations and Open Issues

**Author-stated limitations.**
- The sufficient conditions for each algorithm are worst-case; "in some applications, these worst-case inputs may not be realizable, and thus, the algorithms will perform better for those applications" (p. 1453).
- Closing the gap between the Theorem-5 impossibility curve and the algorithms' curves is left open, as are heterogeneous vehicles with energy constraints and vehicles with fixed service times (p. 1453).
- For arbitrary convex perimeters the two timing quantities remain computable and the analysis extends, but "determining the optimal locations or dominance regions in this case remains an open question" (p. 1453).
- Footnote 1 (p. 1441): extension to double-integrator vehicle models is deferred to future work.
- Heterogeneous capture radii: the extension of Lemmas 3–4 and Theorem 5 is sketched (M equal-time equations; per-vehicle endpoint times ρ sin(β_i) − r_i), and it is only a **conjecture** that Dec-Sweep and Dec-CaC remain 1- and 2-competitive with heterogeneous radii (p. 1453).
- Remark 24: without altitude separation, collision avoidance must be added and D̃ rescaled, lowering the admissible v (p. 1450).

**Critical observations [my observations, with page/eq references].**
- *Intruder model*: intruders are non-responsive (radial motion at fixed speed) throughout the analysis; only a remark claims the fundamental limit and Dec-Sweep "apply as is" for responsive intruders (p. 1453) — no proof is given for the responsive case.
- *Offline idealization*: the competitive ratio assumes O captures every intruder on every considered input (used directly in Theorems 15 and 22); combined with the restriction n_O ≥ 1 (p. 1441), the ratios measure loss against a clairvoyant optimum, which is the standard but pessimistic yardstick.
- *Proof completeness*: Theorem 6 is proven only in outline; Theorems 8 and 10 and Corollary 9 have no proofs in the paper (declared "analogous" to Theorem 6 / [33]); Remark 18's (M+1)/M-competitiveness is not established at all (p. 1445, 1448). A reader needing the Dec-CaC proof must reconstruct it from [33].
- *Restrictive structural requirements*: Dec-CaC/Dec-Sweep need the equal-angle partition (justified by Corollaries 7/9), Coop-CaC needs even M (mitigated only by the unproven modified variant), and Coop-SNP needs M < N.
- *Printed errata* (all verified against the rendered pages): (i) p. 1443, "stream intruders arrive every 1 − ρ/v time units apart" should be (1 − ρ)/v (release times are 1 + k(1−ρ)/v); (ii) p. 1445, Corollary 7's proof prints x_S¹ = min{1 − r, ρ − r} whereas Theorem 6 uses min{1 − r, ρ + r}; (iii) p. 1440, the fifth problem parameter is misnumbered "2) the capture radius" in the contributions list; (iv) p. 1447, Theorem 15 takes the min over m ∈ {1, …, M} although there are M/2 cooperative regions; (v) p. 1449, Algorithm 2 line 9 uses ≥ where the S2 text uses >; (vi) p. 1451, Fig. 8's legend labels the v = 1 curve "Theorem 4" while the caption cites Theorem 5.
- *No lower bounds per algorithm*: the paper never shows any algorithm's competitive ratio is optimal within its regime (e.g., whether 1.5 is achievable-and-necessary for Coop-CaC's regime); the only impossibility result is the finite-c threshold of Theorem 5.
- *Sensing/communication*: no delays, noise, or localization error are modeled; the online algorithms require instantaneous knowledge of all released intruder positions (p. 1441) — a practical gap for the UAV/anti-poaching motivation.
- *Payoff granularity*: performance is the capture count; intruders that are captured after breaching do not count, and partial perimeter penetration weighting is not modeled.

## 8. Citation Value

**Role**: This is the canonical reference for *worst-case (competitive) multi-vehicle perimeter defense in conical environments*. Use it as (a) **related work / gap support** when arguing that game-theoretic reach-avoid and stochastic dynamic-routing approaches assume a priori intruder information or average-case inputs, while arbitrary adversarial release sequences require online-algorithm analysis; (b) **method comparison** as the multi-vehicle extension of the single-vehicle conical-environment line of work ([32], [33]) — its Theorem 5 impossibility frontier and its five algorithms (Dec-Sweep 1, Dec-CaC 2, Coop-CaC 1.5, Dec-SNP (3n_s−1)/2, Coop-SNP (3N−M)/(2M)) are the natural benchmarks against which any new defense policy with capture-radius-limited vehicles should be measured; (c) **background** for capture-radius (disc-capture) vehicle models and dominance-region partition arguments (Lemmas 3–4), which recur in later cooperative perimeter-defense papers by the same group (cf. P009, the randomized companion letter). It is less relevant if your work concerns responsive/strategic evader dynamics, HJI-value methods, or per-intruder optimal differential-game strategies.

**Ready-to-adapt citation sentence**: "Bajaj et al. [P008] consider M capture-radius-limited vehicles defending a concentric perimeter in a conical environment against arbitrarily many radially-incoming intruders released at arbitrary times, and use competitive analysis against an optimal offline algorithm to establish a necessary condition for finite competitiveness, five decentralized and cooperative online algorithms with competitive ratios 1, 2, 1.5, (3⌈θ/(Mθ_s)⌉−1)/2, and (3N−M)/(2M) in disjoint parameter regimes, and the scaling of the achievable frontier with the number of vehicles (IEEE T-Robotics, 2024)."

Shorter variant: "A competitive analysis of multi-vehicle perimeter defense in conical environments proves an algorithm-independent feasibility frontier and designs decentralized and cooperative online algorithms that are 1-, 1.5-, 2-, or parameter-dependently competitive, showing the achievable speed regime grows with the number of vehicles but with a persistent gap to the fundamental limit [Bajaj et al., IEEE TRO 2024]."
